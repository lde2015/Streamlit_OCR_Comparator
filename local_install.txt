How to verify the CUDA installation

    Open a command prompt (on Windows) or a terminal (on Linux).
    Type nvcc --version and press Enter.
    If CUDA is installed correctly, you should see the version of the 
    CUDA Toolkit that is installed, along with the version of the NVIDIA GPU driver.
